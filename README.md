# Zombie Survival: Last Base

Roblox PC·모바일용 로우폴리 좀비 생존·투척·포획·기지 성장 게임.

> 이 저장소는 현재 **게임 기획 및 개발 기준 문서**를 보관합니다. 실제 Roblox Studio 프로젝트·스크립트 전체가 GitHub에 동기화되었다는 의미는 아닙니다.

## 기획 원칙
- 높은 상부 안전 기지와 직선형 하부 위험 지형을 분리한다.
- 참고 영상의 타이밍 게이지·추적 카메라·장거리 투척 구조를 돌/그물에 적용한다.
- 먼 구역일수록 적과 생존자의 레벨·희귀도·위험도가 커진다.
- 좀비 처치·포획, 생존자 구조, 자원 채집으로 고정 부지 건물을 단계적으로 해금한다.
- 일반 생존자는 구조 후 왼쪽 안전 통로로 줄지어 자동 귀환한다. 등에 업기는 특수 구조 방식 또는 테스트 기능으로 남긴다.
