# 11. 참고 영상 분석 기록 — 원본 재검토 대기

> **근거 상태:** 이 문서는 이전 대화에서 남긴 영상 분석 메모와 사용자가 확정한 게임 기획을 구분해 보존한 것이다. **이번 문서화 작업에서는 이전에 업로드된 영상 2개의 원본 파일을 다시 열어볼 수 없었다.** 따라서 아래 항목은 이번에 영상을 재생해 독립 검증한 결과가 아니며, 정확한 타임코드·프레임·원본 UI 수치는 확정하지 않는다. 영상 재업로드 시 직접 관찰 결과로 교체/보강한다.

## 자료 목록
- 참고 영상 A: 이전 대화에서 사용자가 제공한 Roblox 게임플레이 영상. **현재 파일명/링크/길이/해상도 확인 불가**.
- 참고 영상 B: 이전 대화에서 사용자가 제공한 Roblox 게임플레이 영상. **현재 파일명/링크/길이/해상도 확인 불가**.
- 이후 사용자 제공 Roblox Studio 스크린샷: 노란 투척 발판, 빨간 추락 영역, 사다리와 왼쪽 안전 통로, 기지 아래 빈 공간 등은 별도 개발 수정 요청의 근거. **참고 영상 속 장면과 혼동하지 않는다**.

## 과거 대화에 기록된 참고 영상 분석 요약
다음은 과거 대화의 영상 분석 결과로 전해진 요소들이며, **영상 A/B 중 어느 장면에 나타났는지 현재 구분 불가**.

| 요소 | 과거 대화에서 기록된 내용 | 프로젝트 적용 | 근거 수준 |
|---|---|---|---|
| 투척 방식 | 투척 전 세로 방향으로 움직이는 타이밍 게이지 | 노란색 발판에 들어가면 게이지 UI 즉시 표시, PC 클릭/모바일 탭 | 과거 분석 메모; 원본 미재검토 |
| 투척 안내 | '탭하여 던지세요' 류의 입력 안내 | 게이지 활성 시 조작 안내 | 과거 분석 메모; 정확한 문구 미확인 |

| 지형 구성 | 길게 이어지는 직선형 진행 지형과 단계별 구역 | Zone01~Zone05 순차 배치 | 과거 분석 및 사용자 후속 기획 |
| 착탄과 보상 | 멀리 던져 다음 구역으로 진입하는 반복 플레이 구조 | 돌 착탄 Zone의 좀비 처치, 그물 포획, 보상 | 영상 구조 참고 + 사용자 창작 변경 |
| 게임의 보상 루프 | 반복 투척과 단계적 확장 | 전투·수집·기지 해금·성장 루프 | 게임 기획 해석 |

## 참고 영상에서 직접 가져오지 않은 독자 기획
아래는 **사용자가 이후 대화에서 정한 좀비 게임 고유 시스템**이며, 참고 영상의 사실로 기록하지 않는다.

1. 과일 등의 투척물을 **돌멩이(폭발)·그물(기절/포획)**로 교체.
2. 착탄 Zone의 좀비 처치/포획, 도감 및 수용소 전시.
3. 높은 상부 안전 기지와 낮은 하부 전투 지형, 양옆 높은 산, 기지 아래 암벽, 추락 방지 투명 벽.
4. 왼쪽 사다리와 안전 귀환 통로; 좀비 상부·통로 진입 금지.
5. 랜덤 등장하는 웅크린 생존자, 구조 후 **줄지어 자동 귀환**하는 시각적 연출.
6. 생존자 등에 업기 애니메이션과 원거리 구조 아이템·드론 확장안.
7. 건물 24종의 고정 부지/숨김/자원 충족 발판/건설 연출/기능 해금.
8. Zone별 좀비 리스폰 보류 및 상부 복귀 후 재개.

| 참고 요소 | 기능 담당 | 검증 기준 |

| 발사와 비행 | CombatService / ThrowController | 강도와 실제 궤적 일치, 플레이어용 투명 벽 투사체 통과 |
| 카메라 추적 | ClientCameraController | 비행 추적·착탄/사망/취소 후 카메라 복귀 |
| 거리·배율 | ZoneConfig / ThrowHUD | 서버 기준 거리/착탄 Zone 판정과 표시 일치 |

## 후속 조사 체크리스트
- 영상 A/B의 길이, 제목, 업로드 파일명, 서로 다른 게임인지 여부.
- 게이지의 정확한 방향·속도·판정 구간·자동 왕복 방식.
- 발사 순간 투척물 위치·초기 속도·중력·착탄 처리.
- 카메라가 투사체에 붙는 순간과 복귀 조건.
- 배율이 무엇에 곱해지는지, 거리 수치가 studs인지 별도 단위인지.
- Zone 경계·점수/보상·연속 투척·리셋의 정확한 흐름.
- PC/모바일 실제 입력과 화면 배치.

**저작권·개발 원칙:** 참고 영상의 플레이 감각을 분석하되 원본 소스·모델·애니메이션·UI를 무단 복제하지 않고 Roblox 게임에 맞게 독자 구현한다.
