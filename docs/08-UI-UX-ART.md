# 08. UI·UX·카메라·아트

## UI 원칙
Roblox PC/모바일 모두 지원, 화면 중앙 가독성, Safe Area 반영, 터치 목표 충분히 큼, 반응형 배치. 이전 스크린샷에서 큰 왼쪽 BUILD BASE 메뉴가 HUD와 겹쳤음. **고정 발판 구매형**으로 전환하므로 기존 자유 배치 메뉴는 제거/비활성화(서버 기능 교체와 함께 수행).

## 주요 화면
- 상부 발판: 진입 즉시 세로 타이밍 게이지, '탭하여 던지세요' 안내, 선택 무기, 게이지 퍼센트/정확도.
- 투척 중: 카메라 투사체 추적, 거리 및 배율, Zone 이름/레벨, UI 복원 버튼.
- 착탄: 충격파·보상·처치 수, 포획 성공/실패 원인.
- 생존자: 웅크린 NPC의 레벨/희귀도, 구조 ProximityPrompt, 귀환 행렬 현황, 도착 성공 알림.
- 기지: 각 건물 앞 잠금/구매 가능/건설 중/완료 발판, 비용과 부족량, 공사 애니메이션.
- 도감: 발견/처치/포획, 종류/레벨/희귀도, 수용소 가용 칸.
- 자원 HUD: 코인, 나무, 돌, 철; 나중에 식량·부품 접기.

## UX 상태와 오류
- 건물 발판 Locked 회색/ Affordable 초록/ Building 연출/ Built 제거·완료.
- 구매 직전 서버 재검증; 이미 구매, 남은 자원 부족, 저장 중, 타인 부지 등의 안내.
- 발판 진입·재진입·캐릭터 리스폰 시 중복 UI 금지.
- 모바일 가상 조이스틱·점프 버튼과 ATTACK/ TRAIN/ 구조 버튼 겹침 방지.
- 기본 훈련 HUD와 건설 HUD는 위치 구분, 숨김/접기 및 화면 비율에 따른 배치.

## 아트
밝고 단순한 로우폴리 3D 카툰. 초원/폐허/협곡/오염 연구소/벙커 지형을 단계별로 톤 구분. 상부 기지는 초록 잔디, 목재 울타리·밝은 석재; 하부는 높고 입체적인 산악 측벽. 기지 밑 빈 벽은 다면체 암반으로 메꿈. 시각 효과는 모바일 성능 고려.

## 애니메이션
투척 준비·릴리스, 돌 폭발·그물 펼침, 웅크림→구조, 행렬 걷기, 등에 업기/내려놓기, 건물 순차 공개, 작업장 생산. Studio 애니메이션 자산 공개권·권한과 R6/R15 호환 테스트 필요.

## 성능
Zone별 장식 거리 기반 간소화, 시각 효과 파트 재활용, 물리 소유권 서버 우선, 레벨·희귀도 UI 먼 거리에서는 숨기기, NPC 수 제한.
