# 00. 종합 게임 기획서

## 제품 비전
**Zombie Survival: Last Base**: Roblox PC/모바일, 로우폴리 3D 카툰 스타일. 높은 개인 기지 위에서 타이밍을 맞춰 돌·그물을 먼 하부 구역에 던지고, 좀비를 처치·포획하며 생존자를 구조한다. 수집과 자원 생산으로 지정된 기지 시설을 하나씩 공개하고 더 먼 위험 지대에 진출한다.

## 핵심 플레이 루프
1. 상부 안전 기지에서 투척 발판 진입 → 세로 게이지 활성화.
2. 타이밍 맞춰 돌 투척 → 하부 Zone에 착탄·폭발 → 좀비 처치, 코인·XP 등 보상.
3. 그물 투척 → 좀비 기절·포획 → 상부 수용소·도감에 기록.
4. 위험을 정리한 뒤 플레이어가 사다리로 하부에 내려가 생존자를 발견·구조.
5. 일반 구조 생존자는 왼쪽 안전 통로를 따라 줄지어 기지로 자동 귀환(현 최종 선호). 직접 등에 업는 모션은 특수 구조 미션 또는 선택 가능한 기능.
6. 채집·전투·구조로 자원과 코인 모음 → 고정 건물 앞 발판 구매 → 건설 애니메이션 → 실제 기능 개방.
7. 무기/그물/훈련/자동 생산을 강화하여 더 먼 Zone과 높은 등급 수집에 도전.

## 플레이 핵심 경험
- 영상 속 과일 투척의 **타이밍 게이지, 긴 비행, 추적 카메라, 거리/배율** 구조를 참고하되 코드·모델·정확한 수치는 독자 설계.
- 투척 성공 및 폭발의 즉각적인 보상; 높은 레벨 Zone에 정확히 착탄하는 기술적 목표.
- 하부는 기지보다 낮아 지형으로 안전성이 드러나고, 좀비 AI는 안전 구역을 추적하지 않음.
- 여러 구조 생존자가 줄을 지어 오는 시각적 피드백과 수집의 즐거움.
- 기지에 미리 정해진 건물이 순차적으로 공개되어 성장감을 줌.

## 확정된 구조
- 상부 개인 안전부지, 하부 길고 직선형 Zone01~Zone05, 양쪽 높은 산/암벽.
- 사다리로 하부 접근, 왼쪽 안전 통로는 좀비 진입 금지, 막힌 상단 천장/바닥 출구 개방.
- 멀어질수록 좀비/생존자 레벨과 희귀도 상승; 레벨과 희귀도는 별개 속성.
- 기본 돌멩이는 하부 착탄 지점이 속한 Zone의 좀비를 폭발로 처치한다는 최신 개발 요청. 밸런스를 위해 범위 제한 방식은 추후 검토.
- 웅크린 생존자 NPC 랜덤 등장, 구조 후 기지 정착 및 일자리 배치.
- 건물 위치 고정, 숨김 상태 → 자원 충족 → 발판 활성화 → 건설 애니메이션 → 건물 공개.

## 미완료 및 의사결정 분리
- 과거에 요청한 코드는 **요청/기획**이지 구현 검증 결과가 아님.
- 영상의 정확한 투척 물리식·배율식·Zone 실제 거리·원본 애니메이션은 확인되지 않음.
- 생존자 일반 귀환은 자동 행렬로 최종 선택했으나 ‘등에 업고 사다리 올라오기’ 실기능도 후속 요청함. 기본 자동 귀환 + 특수 업기 모드로 병행하고 플레이테스트에서 조정.
- PvP/멀티플레이어 기지 소유, 세이브 실패 정책, 레어 확률, 무기 수치, 수용소 건물 위치는 설정과 테스트 후 확정.

## 1차 완성 정의(MVP)
- 떨어지지 않는 상부 기지와 전체 5개 Zone 베이스, 안전 사다리·통로.
- 투척 발판/게이지, 돌 비행 및 폭발로 Zone01 좀비 처치, 그물 기절·포획.
- Zone01 랜덤 웅크린 생존자, 구조 후 안전 통로를 통한 기지 귀환.
- 최소 3개 고정형 구매 발판과 건설 공개 및 데이터 재접속 복원.
- UI 모바일·PC 가독성, 다중 접속 서버 검증, 정상적인 저장·복원.
