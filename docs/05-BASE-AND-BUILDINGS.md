# 05. 기지 건설·24개 건물 해금 설계

## 시스템 전환
기존 BUILD BASE 메뉴에서 Wall/Tower/Generator/Storage를 자유 배치하는 방식을 **고정 부지 타이쿤**으로 교체한다. 모델은 ServerStorage.BuildingModels에 보관하고, Workspace.PlayerBases에 플레이어별 부지/고정 위치를 배치. 구매 전에는 완성 모델이 보이지 않고 충돌하지 않도록 처리한다.

각 건물 앞 바닥 구매 발판 상태: **Locked(회색)** → **Affordable(초록)** → **Building(애니메이션)** → **Built(완료/발판 제거)**. 선행 건물/자원 충족 시 발판 활성화. 플레이어가 밟으면 서버에서 소유권·자원·선행 조건을 재검증하고 원자적으로 차감, 바닥→기둥→벽→지붕 공개 연출 및 효과음·파티클. 중복 Touched·중복 구매·재접속 시 이중 차감 방지. 건물 상태를 영구 저장한다.

**비용과 순서는 초기 기획 제안이며 플레이테스트 전 확정 아님.**

## 기능 연동 원칙
- 좀비 수용소 해금 전 그물은 기절만 가능, 실제 포획/저장은 수용소 슬롯 확인 후 가능(제안).
- 생존자 숙소가 없어도 구조 기록/대기명단은 보존, 작업장 배치는 숙소와 작업장 해금 후.
- 채집·생산은 서버가 보유 자원과 배치 생존자 능력을 계산. 건물 UI만 열렸다고 서버 기능이 활성화되는 것이 아님.
- 전력·도구·연구 등 선행 해금은 GameConfig/BuildingConfig에 데이터화.
- 기존 `Buildings` 저장 데이터는 삭제 금지. 기존 자유배치 건물과 새 고정 건물 상태를 마이그레이션/분리.
- 건물 구매 발판이 부지의 안전한 이동을 방해하지 않도록 배치하고, 모바일 HUD를 가리지 않는다.

## 우선 구현
울타리, 창고, 채집 도구 작업대, 투척 훈련장, 무기 제작대, 그물 제작소, 좀비 수용소, 생존자 숙소, 구조 관리소. 나머지 15종은 부지·모델·해금 그래프를 먼저 설계한 뒤 확장한다.
