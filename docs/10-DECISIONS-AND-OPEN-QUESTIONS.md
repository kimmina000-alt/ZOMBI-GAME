# 10. 결정 기록과 미결 목록

## 확정된 사용자 의사
- Roblox Zombie Survival: Last Base, PC/모바일, 로우폴리 카툰.
- 영상 속 과일 투척의 조작/카메라/거리 배율 구조를 참고한 돌·그물 투척.
- 상부 안전 기지 + 낮은 하부 직선형 월드. Zone 멀수록 레벨·희귀도·험준함 증가.
- 상부에서 좀비 처치·포획, 하부는 사다리로 접근, 좀비는 상부·왼쪽 안전 통로 침입 금지.
- 양쪽 높은 산악 벽을 상부 기지 바닥 높이까지, 기지 밑 빈 공간 암벽으로 채움.
- 투척 발판 진입 즉시 움직이는 세로 게이지, 끝에서 추락 방지.
- 돌멩이 착탄 폭발, 요청 당시 착탄 Zone 좀비 전부 처치.
- 생존자 웅크린 상태로 랜덤 스폰, 플레이어가 직접 구조. 최근 최종 선호는 여러 명이 **줄지어 자동 귀환**, 중간에 직접 업고 사다리 이동/모션 요청도 존재. 둘 다 기능 후보.
- 기존 선택 건설 UI 대신 고정 건물 부지 숨김→발판 터치 구매→건설 애니메이션→공개. 자원 소비에 Wood/Stone/Iron/Coins.
- 기능이 잠긴 건물을 해금해 성장하는 타이쿤 구조.

## 설계 제안값(확정되지 않은 수치)
- 높이 차 약 70 studs.
- Zone01 Lv1~5/Zone02 Lv6~15/Zone03 Lv16~30/Zone04 Lv31~50/Zone05 Lv51~100.
- Zone 정리 후 상부 대기 45초, 하부 체류 중 리스폰 보류, 모든 구조 인원이 귀환 후 10초.
- 건물 24종 비용과 해금 흐름은 docs/05-BASE-AND-BUILDINGS.md의 초안.
- 공용 Rarity: Common, Rare, Epic, Legendary, Mythic.

## 변경 이력
1. 초반에는 기지 밖 하부로 내려가 생존자를 등에 업고 돌아오거나 귀환 아이템/스킬을 사용.
2. 이후 일반 생존자는 **구조 후 안전 통로를 따라 자동으로 줄지어 복귀**하는 안에 동의. 직접 업기는 특수 임무에 남기기로 정리.
3. 추후에는 등에 업는 실제 애니메이션 구현 요청도 있었으므로 완전 삭제하지 않고 모듈 분리.
4. 건물은 원래 자유 배치(선택 UI) → **미리 배치된 건물 구매 발판형 타이쿤**으로 전환.
5. 예전엔 별도 ZombieCaptureServer 추가를 제안했지만, 실제 코드 분석 후 비활성 ZombieSystemServer를 확장하는 단일 권한 방향 제안.

## 앞으로 결정할 것
- 일반 생존자 직접 업기 허용 범위(특수 임무 한정/선택 전환).
- 돌 폭발이 해당 Zone **전체 즉사**일지, 폭발 범위/레벨 제한을 적용할지.
- 포획 시 그물 한 번의 구역 전체 처리 여부와 수용소 필수 조건.
- 생존자/좀비 희귀도 정확한 확률표.
- 각 건물 배치 좌표, 복수 플레이어별 개인 부지/공유 월드 상호작용.
- 자동 귀환 NPC의 사다리 통과 방식(직접 climb vs NPC 전용 우회/리프트).
- 건설 구매 발판이 자동 구매인지 확인 UI를 거칠지(발판 터치만으로 구매 요청).
- 플레이어가 하부에 남아 있을 때 다른 플레이어의 리스폰 타이머 범위.
- 생존자 구조가 숙소 전에 가능할 때 대기 목록 최대 용량.
- 작업장 오프라인 생산/에셋 최종 선정.
