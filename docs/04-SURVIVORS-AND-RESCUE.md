# 04. 생존자 생성·구조·귀환·일자리

## 발생
- 하부 각 Zone의 SurvivorSpawns에 랜덤 출현; 일정 주기·동시 상한·중복 방지.
- Level과 Rarity는 분리. 기지에서 먼 Zone일수록 높은 레벨과 희귀 등급 확률 상승.
- 기본 상태: **쭈그리고 앉거나 웅크린 생존자**; 구조 요청 아이콘·레벨·희귀도 표시.
- 실사급이 아닌 Roblox R15/R6 리그에 맞는 애니메이션. 직접 제작·라이선스 에셋 필요 시 교체 가능하도록.

## 구조 상호작용
- 플레이어는 상부에서 돌/그물로 몬스터를 정리한 후 사다리로 내려감.
- E 또는 모바일 ProximityPrompt로 구조 요청. 서버는 거리, NPC 생존 여부, 상태, 구역, 구조 소유권, 중복 요청 검증.
- 구조 버튼 후 해당 생존자의 구조 예약과 이동 상태 전이. 도착 후 영구 등록 및 구조 보상, 중복 지급 차단.

## 기본: 자동 귀환 줄서기
최근 합의한 일반형: **생존자 발견→플레이어가 직접 접근·구조→NPC가 왼쪽 안전 통로로 자율 이동→동시에 구조하면 간격 유지하며 줄지어 기지 도착→숙소/대기명단 등록**.
- 하부 위험 공간을 빠져나가 안전 통로에 진입하면 좀비의 추격/공격 대상 제외.
- 출발/통로/사다리/상부 도착 지점에 Waypoint 명명. 사다리가 NPC 경로에 부적절하면 NPC용 완만한 우회로·리프트/연출용 이동 구성.
- 여러 NPC 충돌 최소화: 경로 큐, 간격, 속도 제한, 보정 웨이포인트.
- 길 막힘·NPC 리셋·장거리 이동 실패 시 서버가 소유권을 유지하고 마지막 안전 지점에서 복원/일정 시간 후 안전 도착 처리.

## 추가: 등에 업기
중간 단계에서 직접 업고 사다리 올라가기, 등 부착과 업기 애니메이션을 요청한 이력이 있음. 최종 일반형 자동 귀환과 충돌하지 않도록 **특수 구조 미션 또는 수동 선택 방식**으로 별도 구현.
- 한 플레이어당 한 NPC, 운반 리그의 충돌·무게·움직임 조절, Weld/AnimationController 상태 분리.
- 직접 업기 시 사망/접속 종료/사다리 통과·복귀 좌표 처리, 상부 도착 시 등록.
- 일반 자동 귀환과 수동 업기 중 동일 NPC 이중 처리 금지.

## 배치·역할
Worker/Logger/Miner/Farmer/Engineer/Medic/Scientist 등의 직업 후보. 숙소 수용 인원/작업장 슬롯을 서버 검증. 레벨/희귀도에 따라 생산 효율과 특수 능력 차이.
- 숙소가 없어도 구출된 생존자는 **대기 명단**에 저장; 배치만 해금 조건 적용.
- 위험 지역 구조 실패/접속 종료 때의 NPC 재등장·예약 해제 정책은 플레이테스트로 결정.

## 수락 기준
모바일·PC 구조 프롬프트, 희귀도 UI, 줄서서 실제 귀환, 다른 플레이어 구조 소유권 격리, 중복 지급 방지, 재접속 보존, 숙소 미해금 대기명단, 특수 등에 업기 애니메이션 확인.
